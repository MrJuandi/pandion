# Gate before the first policy-training run

**Status:** not ready for physical or geographic claims, 2026-09-28. The existing FM1 integrated episode may be used for an explicitly exploratory controller experiment. Passing unit and synthetic integration tests does not make its outcomes evidence of real-world suppression effectiveness.

The following gate applies to a **result-bearing geographic or physical comparison**, not to a labeled synthetic decision-interface experiment. Exploratory results may compare controllers and baselines within the frozen simulator, but must report its scenario, seed, water-effect assumption, code version, and limitations, and must not be mixed with validated-incident results.

| Gate | Required evidence | Current state |
|---|---|---|
| Scenario and provenance | Versioned map/time contract, fuel, terrain, moisture, weather, ignition, resource data, source/version/date/license and split assignment | Synthetic examples only, including a hand-assigned GR1/SH1 map. EMSR578 AOI01 polygons audited, but matching inputs and a documented geographic fuel crosswalk are absent. |
| Spread equation and numerical behavior | Source-matched local equation checks; varied fuel/wind/slope/grid comparisons; selected resolution justified for the endpoint | FM1 one-size equations and one published figure check done; Pyretechnics standard-fuel local rates are now connected to a separate synthetic grid-arrival solver. Seven homogeneous sensitivity cases show 25 m versus 5 m area differences from −3.94% to +19.05%. Heterogeneous resolution and alternative-scheme checks are absent. |
| Independent physical validation | No-intervention spread compared with observed perimeters at matching times, with uncertainty and incidents kept separate from calibration | Annaburroo fixed-FM1 plot-rate diagnostic has 0.5264 m/s MAE across 120 plots; this does not validate Spanish spread. EMSR578 cannot validate the current fire paths without fuel/weather reconstruction and accounting for suppression. |
| Aircraft and water action | Sourced travel/pickup/drop constraints, deposition footprint, water-effect and persistence model, volume/time invariants, uncertainty ranges | Synthetic movement and full-volume accounting integrated with a permanent 35 m grid barrier. No sourced water response, persistence, or uncertainty range. |
| Controller information | Versioned observation schedule, latency, missingness/error, action candidates generated from observation, leakage tests | Synthetic capture/delivery/coverage and observation-only candidate/action tests done. Real sensor error absent. |
| Evaluation protocol | Primary endpoint/horizon, fair no-intervention/random/heuristic baselines, geographic train/validation/test split, seed and checkpoint protocol fixed before test | Three synthetic baselines implemented with per-run records. Geographic split, calibration, and frozen result-bearing protocol absent. |
| Training interface | Headless step/reset contract, resource limits, action mask, reward with units and exploit checks, replay and checkpoint metadata | A deterministic reset/step wrapper, observation-derived valid action list, incremental affected-area reward in hectares, and terminal replay are implemented. A prior exploratory linear-policy trial opened four synthetic reserved outcomes; that controller is no longer maintained. A broader reward exploit audit and geographic training contract remain absent. |

The [standard-fuel physical-evidence plan](STANDARD_FUEL_PATH.md) starts with a pilot data inventory and candidate vegetation-to-fuel crosswalk. Its next evidence step is a pilot with **matched time-stamped fuel, terrain, weather, and fire perimeters**, plus at least one separate incident reserved for testing. Candidate EMSR578 AOI01 is described in [VALIDATION_EMSR578.md](VALIDATION_EMSR578.md). If credible source matching or incident independence cannot be achieved, document that limitation and keep training as exploratory rather than claiming a validated environment.

The repository now includes a minimal development-only PPO smoke path. It is an exploratory synthetic interface check, not a selected checkpoint or physical-readiness evidence. Validation and reserved splits remain unopened by its default command.

An exploratory synthetic decision challenge has four inspected development cases with both heuristic wins and losses against the random-policy mean. A prior exploratory linear controller was evaluated once on four challenge cases that were reserved until its selection. Its implementation has been removed. Its mean final area was 2.125 ha versus 2.1875 ha for the heuristic and 2.10625 ha for the random-policy mean; this small four-case difference does not establish superiority. Both this challenge's and the earlier eight-variant diagnostic's reserved outcomes are now open and cannot be reused as untouched tests. None of this satisfies a physical gate in the table above.

The independent grass-rate diagnostic and its limits are in [VALIDATION_ANNABURROO.md](VALIDATION_ANNABURROO.md). Its error is a reason to retain the physical-validation gate rather than to tune FM1 on this same collection and call it validated.

No pull request is to be described as “training ready” for physical claims until every row has linked evidence. An exploratory training interface can be implemented and exercised earlier, provided its reward and action mask are tested and its comparisons remain explicitly synthetic. Repository tests and documentation checks must pass, and the pull request must follow `.github/pull_request_template.md`. Scientific readiness is distinct from code review readiness.
